# متجر النون — نسخة كاملة

هذا المشروع ليس صفحة HTML فقط؛ هو متجر بسيط يعمل بـ Node.js + Express، وفيه:
- واجهة متجر RTL متجاوبة للموبايل والآيفون والكمبيوتر.
- سلة مشتريات.
- عرض تلقائي: 1 منتج بالسعر الأساسي، و2 بالسعر المخفض إذا تم ضبطه.
- نموذج طلب مع الاسم والهاتف والعنوان وإرفاق صور.
- إرسال الطلب إلى واتساب رقم 01012029678.
- لوحة إدارة لإضافة وتعديل المنتجات ورفع صورها.
- تخزين المنتجات في `data/products.json`.

## التشغيل على الكمبيوتر
1. ثبّت Node.js.
2. افتح مجلد المشروع في Terminal.
3. شغّل: `npm install`
4. شغّل: `ADMIN_PASSWORD=ضع_كلمة_سر_قوية npm start`
5. افتح `http://localhost:3000`
6. لوحة الإدارة: `http://localhost:3000/admin`

على Windows PowerShell يمكن تشغيله مثلًا:
`$env:ADMIN_PASSWORD="كلمة_سر_قوية"; npm start`

## إضافة منتج
ادخل إلى `/admin`، اكتب كلمة مرور الإدارة، ثم اسم المنتج والسعر والوصف وارفع الصورة. لو يوجد عرض مثل المنتج الحالي، ضع `2` في عدد العرض و`700` في سعر العرض.

## النشر
يمكن رفع المشروع على أي استضافة تدعم Node.js. قبل النشر غيّر `ADMIN_PASSWORD`، وتأكد أن مجلد المشروع قابل للكتابة لأن المنتجات والصور تحفظ داخله.
